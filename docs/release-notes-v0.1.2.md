# WebScribe v0.1.2

本次更新改善了链接输入体验，新增「相似链接合并为同一文档」与跨任务追加，
并加入许可证文件。

## 新增

### 链接输入改为逐条列表

原先是一个多行文本框，链接过长时不便核对，也容易把两个链接写在同一行导致
解析错乱。现在改为：

- **粘贴区**：一次可粘贴多个链接；**一行里挤了多个链接也会被正确拆开**，
  不会连成一个畸形地址（这是最常见的输入错误）
- **链接列表**：每条链接独占一行，带序号，横向滚动显示完整地址，悬停可看全文
- **逐条校验**：实时标出「格式不正确」「尚未填写」「与第 N 条重复」，
  并显示这一条将被并入哪份文档
- 支持逐条修改、逐条删除、手动加一行、整表清空，也可直接把链接拖进列表

### 相似链接合并为同一文档

同一目录下的多个链接视为同一套文档的不同章节，合并输出为一份文档。

判定规则：**同主机 + 路径去掉最后一段后相同**。例如下列三个链接会合并为一份：

```
https://example.com/docs/a/chapter-1
https://example.com/docs/a/chapter-2
https://example.com/docs/a/chapter-3
```

界面上每条链接都会显示它将被并入哪份文档，可随时关闭该行为（
「相似链接合并为同一文档」开关）。

### 跨任务追加

任务结束后再次抓取**相似链接**时，若上次产出的文档仍然存在，新内容会
**追加到该文件末尾**（以 `---` 分隔），而不是另建一份文档。

- 判定依据保存在 `%APPDATA%\com.webscribe.app\merge-records.json`
- 该记录只保存「文档分组 → 产出文件路径」，不含任何抓取内容或认证信息
- 上次的文件若已被移动或删除，会退化为新建文档
- 界面上提供「清除合并记录」按钮，清除后一律新建文档

> 这是本工具唯一的持久化状态，不是数据库，可随时删除。

### 界面显示版本号

标题栏现在显示当前版本（如 `v0.1.2`），版本号取自主程序，单一来源。

## 修正

- 链接解析现在会把「一行多个链接」正确拆分，此前这种情况会产生一个畸形地址
- 链接数量上限的判断改为按**有效唯一条目**计数，重复项不再占用名额
