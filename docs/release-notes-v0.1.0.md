# WebScribe v0.1.0

首个发布版本，对应需求文档第一阶段。

## 产物

| 文件 | 大小 | 说明 |
|---|---|---|
| `WebScribe-Setup-x64.exe` | 250 MB | 安装版。当前用户安装，无需管理员权限，自动创建开始菜单快捷方式 |
| `WebScribe-Portable-x64.zip` | 356 MB | 便携版。解压后双击 `WebScribe.exe` 即可使用 |

两个版本均已内嵌 Node 运行时与 Chromium，**使用者无需安装 Node.js、Rust、Python、Git 或任何开发环境**。

> 体积主要来自 Chromium（约 700 MB 未压缩）：动态页面渲染、登录窗口与 PDF 生成都依赖它。
> 若只需抓取静态网页，可自行删除 `runtime\browsers`，程序会在界面提示浏览器运行时缺失。

## 功能

- 一次任务最多 **10 个 URL**，超出时明确提示，不静默截断
- URL 合法性校验、规范化、同任务内查重
- 按**注册域（eTLD+1）**识别同站 —— `example.com`、`www.example.com`、`docs.example.com` 视为同一站点
- **HTTP First**：普通页面只走轻量 HTTP 请求；仅当正文不足或页面依赖 JavaScript 时才启用浏览器
- 正文提取（Mozilla Readability），自动剥离导航、侧边栏、页脚
- Markdown 输出保留 H1–H6、段落、粗体、斜体、链接、图片、有序/无序列表、表格、引用、行内代码、代码块
- 可选 PDF 输出，保留中文、表格、代码与图片
- 图片可保留远程链接，或下载到同名 `.assets` 目录实现离线存档
- 同站长文多页自动接续为单份文档（默认关闭，上限 5 页），亦可选择每页独立输出
- 用户主动登录后保存登录态，后续抓取自动复用
- 实时任务表格：状态、当前步骤、进度、错误信息、输出文件

## 安全与合规

这一部分是本项目的核心约束，不是附加说明。

**不绕过任何网站防御机制。** 遇到验证码、Cloudflare Challenge、403 访问拒绝等情况时，程序停止自动抓取、向用户显示原因、等待用户处理。明确不实现：CAPTCHA 破解、Challenge 绕过、WAF 绕过、IP 封禁绕过、频率限制绕过、浏览器指纹伪装、代理池、IP 池、MFA 绕过、访问控制绕过。

**抓取行为克制。** 同站串行 + 跨站并行（上限 3），同站两次请求间隔至少 1 秒，有限重试（上限 3 次）并采用指数退避。

**robots.txt 默认严格遵循。** 您手动填写的 URL 始终可抓取（这是您明确表达的意图）；该设置约束的是程序自动续页发现的页面。

**凭据绝不落盘到日志。** 日志按白名单记录字段，并对 URL 查询串中的敏感参数（token、api_key、password、session 等）、Authorization / Cookie / Set-Cookie 整行做脱敏。密码、Cookie、Token、Session ID 均不写入日志。

**登录态只存本机。** 用户在浏览器窗口中自行输入账号、密码、验证码与二次验证，程序不读取也不保存明文凭据。登录态保存在 `%LOCALAPPDATA%\com.webscribe.app\auth\`，该路径已在 `.gitignore` 中排除。

**无数据库、无云端、无账号体系、无遥测。** 所有处理均在本机完成。

## 已知限制

- **仅提供 Windows x64 版本。** ARM64 不在第一阶段交付范围内。
- **界面交互未经自动化验证。** 「输入 URL → 选择保存位置 → 开始抓取」这一链路需要人工在界面上走一遍；保存位置涉及系统对话框，自动化点击可靠性不足，未强行实施。
- **不使用 `@yao-pkg/pkg` 打包。** Tauri 官方指南推荐该方案，但其虚拟文件系统与 Playwright 的 `child_process` 驱动分叉存在已知冲突。Playwright 是硬性依赖，故改为捆绑 `node.exe` + 明文 JS 文件，代价是体积略大且抓取模块以明文分发。
